# Security Radar

毎朝10時（日本時間）ごろに公開セキュリティ情報を収集するGitHub Pagesサイト。

## 構成

GitHub Actions → xAI Responses API（X Search + Web Search）→ 構造検証 → JSON履歴保存 → GitHub Pages。
指定アカウントは `config.json` で変更可能。検索は全投稿の網羅取得を保証しません。
公開情報のみを扱います。社内の資産台帳、認証情報、対応履歴はここに保存しないでください。

## 設定と実行

- Repository Secret `XAI_API_KEY` にxAIのキーを登録。
- PagesのSourceをGitHub Actionsに設定。
- Actionsの **Daily security radar → Run workflow** で手動実行。
- 定期実行はJST 10:07、10:37、11:07。同日に成功済みなら追加のAPI呼び出しをせず終了。GitHub側の混雑で遅延・未実行になる場合があり、10時の更新は保証されません。
- JSON Schemaによる構造化出力で、タグ・出典などの必須項目をAPI側にも指定しています。
- ローカル検証は `npm test`。収集は環境変数を設定して `npm run collect`。

## 費用保護

`monthlyRunLimit: 35` で、初期設定は月最大35リクエストです。実課金の上限を保証するものではありません。初回の実利用量をConsoleで確認してください。
APIエラー時も実行枠を消費し、繰り返しの有料実行を抑えます。`docs/data/usage.json` に月別実行数を保存。
検索ターン数・出力トークン数を制限。1リクエストのツール実行数と実費は変動します。
xAI側の自動チャージや後払いはこのプロジェクトでは有効化しません。残高・実費はConsoleで確認してください。

## 検証と制約

構造・分類・HTTPSリンク・公式出典の存在はコードで検証。個々の事実や出典の真正性はAIによる調査であり、人による確認が必要です。
該当環境は未判定。確認手順と公式情報を参照してください。
収集失敗時は前回データを保持し、失敗状態を公開。APIレスポンスやキーをログに出力しません。
ブラウザーでは取得内容をHTMLとして挿入せず、テキストとして表示します。
